# units.txt — F3c mobile unit sprites.
#
# One static 16x16 frame per unit, except nuke (32x32). Palette "natural":
# h is the hull/body grey, m the sail, wake and highlight, k the ink outline
# and shadow, b/r/a the wooden and metal train stock, y the cargo and warning
# markings. P/B/C are the player's fill/border/accent slots, so ownership is
# readable from the unit itself.
#
# Names are art names, not engine type strings: the selector in
# pixel/unitSprites.ts maps the engine types to these slots. That keeps the
# requested art vocabulary (submarine, torpedo, flak) while the engine still
# only knows Transport, SAMMissile and MIRV Warhead.
#
# No animation: @fps 0 and one @frame per sprite. The instance buffer reserves
# one byte for a frame index, so an animated nuke can be added without a new
# buffer layout.
