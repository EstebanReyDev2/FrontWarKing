# world.txt - F3d terrain decoration sprites.
#
# Three static 16x16 props, palette "natural". They are drawn by
# TerrainScatterPass on a deterministic subset of land tiles:
#
#   tree  - 2x2 tiles, forest canopy (f/g) over a wood trunk (b)
#   rock  - 1x1 tile, highland/mountain greys (h/m)
#   hut   - 2x2 tiles, plaster walls (a) and a brick roof (r)
#
# `@world` is the footprint in tiles. Trees and huts are deliberately larger
# than one tile so they stay readable at the zoom where decor appears; rocks
# are small enough to sit inside a single tile. The scatter pass flips some
# instances horizontally from the instance hash, so one drawing per prop is
# enough variety.

@size 16 16
@palette natural
@anchor center
@fps 0
@world 2 2
