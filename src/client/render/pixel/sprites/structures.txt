# structures.txt — F3b structure sprites.
#
# One 32x32 frame per structure, palette "natural" (16 slots: 12 fixed colours,
# P/B/C player slots, transparent). Buildings use b (wood), r (brick) and
# a (plaster) as the base; k is the ink outline; the player's roof, banner or
# painted band uses P/B/C so ownership is readable without the old colour disc.
#
# All six are 32x32 on purpose: the pass draws every structure over the same
# icon footprint, so a 16x16 sprite would show texels twice as large as a 32x32
# one next to it. One texel grid for the whole family.
#
# Levels: the selector looks for <name>_l<level> and falls back to <name>.
# Only the base art ships in F3b; level variants can be added later without
# touching the pass.
